# Scrollytelling Portfolio Prototype (Spec-Driven)

## Project Description
This project is a small test build that demonstrates scrollytelling using a spec-driven development process. It includes a section-based homepage narrative and one supporting content page.

The build approach is adapted from:
- https://github.com/kaw393939/scrollytelling_spec_driven
- https://github.com/kaw393939/bseai_degree

## Live Site
- https://vangela6780.github.io/is117SpecDriven/

## Structure
- index.html: 5-section scrollytelling homepage (hero, context, solution, features, CTA)
- why.html: supporting content page with standard scroll layout
- css/styles.css: shared design system and page styles
- js/scroll.js: scroll-triggered reveal animation logic
- images/: folder for project images
- mini-spec.md: sprint-1 mini-spec and acceptance criteria
- sprint-plan.md: five-sprint execution plan

## Process Used (Spec-Driven)
1. Define references and constraints first.
2. Write a mini-spec before coding.
3. Build in small phases (structure -> animation -> content -> polish).
4. Verify links, layout, and scroll behavior at each step.
5. Keep diffs simple and readable.

## What I Learned
- Writing specs first creates clearer implementation decisions.
- Scrollytelling helps communicate complex ideas with better pacing.
- AI is more effective when given explicit constraints and acceptance criteria.

## Run Locally
1. Open the project folder in VS Code.
2. Open index.html in a browser (or use a local server extension).
3. Scroll through all five sections and test links to why.html.
